# Agent Plugins schemas

`plugin.schema.json` and `mcp.schema.json` for Agent Plugins 1.0.0 and 1.1.0, copied unchanged from
[agentplugins/agent-plugins-spec](https://github.com/agentplugins/agent-plugins-spec/tree/main/schemas)
(commit `ff8ab5e`, 2026-08-19) for `scripts/validate`, which must not fetch schemas while it runs.
